= Plurimath Open Project Site

== Introduction

This is the Plurimath project site,
part of Ribose Open Project network,
located at https://www.plurimath.org.

It is a https://jekyllrb.com[Jekyll]-based site
created with the Open Project Jekyll theme.

Refer to their respective docs for details.


== Content management

=== Function pages

The pages under `functions/` are generated by the `plurimath` gem. Do not edit
them by hand. Each function has an entry in `_data/functions.yml` that gives
one example in one source format, the formats to show, and any notes. The
other examples are converted from that source by the gem.

* Run `bundle exec rake functions:generate` to rewrite the pages
* Run `bundle exec rake functions:check` to verify they are up to date

The site build regenerates the pages with the installed gem, and pull requests
fail when the committed pages differ from what the gem produces.


== Development

=== Getting started

* Ensure you have a suitable Ruby version and Node.js 22 or newer
* Run `git submodule update --init javascript/plurimath-ts` to fetch the pinned TypeScript converter
* Run `npm ci` and `npm run build:converter` to build the browser bundle
* Run `bundle` from within site directory to install Ruby dependencies

=== Serving site preview

* Run `bundle exec jekyll serve` from within the site directory

The playground uses the native TypeScript converter from the pinned
`javascript/plurimath-ts` submodule. It does not require an npm release or Opal.
Rebuild with `npm run build:converter` after changing the pinned source.
