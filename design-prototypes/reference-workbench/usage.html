Getting started

Install Plurimath, parse one expression, and serialize it into another mathematical representation.

Goal

By the end, sin(1) will exist as a formula object and serialize to LaTeX or MathML.

Ruby

1. Install the gem

Add Plurimath to your application’s Gemfile, then install dependencies.

Gemfile
gem "plurimath"

2. Parse a source expression

Plurimath::Math.parse accepts the source string and its representation type.

Ruby
asciimath = "sin(1)"
formula = Plurimath::Math.parse(asciimath, :asciimath)

formula.to_latex
# => "\\sin1"

3. Choose another serializer

The same formula object can serialize to AsciiMath, LaTeX, MathML, UnicodeMath, HTML, or OMML.

sin⁡(1)

JavaScript

Install from npm

Shell
npm install -S @plurimath/plurimath

Use the ES module

JavaScript
import Plurimath from "@plurimath/plurimath";

const formula = new Plurimath(
  'ubrace(1+2+3+4)_("4 terms")',
  "asciimath"
);

console.log(formula.toLatex());
