API reference

Start with the runtime you use. Browser methods are separated from Ruby-only arguments so the interface never implies parity that does not exist.

JavaScript browser surface

Exact surface

These methods come from the local dist/index.d.ts facade used by the converter.

Constructor

JavaScript
new Plurimath(data: string, format: Format)

Parses source data in AsciiMath, LaTeX, MathML, HTML, UnicodeMath, or OMML and stores the formula model.

Serializers

JavaScript
toAsciimath() · toLatex() · toMathml(intent?) · toHtml() · toOmml() · toUnicodemath()

Each serializer returns a string. The browser facade currently exposes one direct serializer argument: optional semantic intent for MathML.

Display helper

JavaScript
toDisplay(lang: string)

Returns a display representation using the requested language identifier.

Ruby parse and serialize

Plurimath::Math.parse

Ruby
Plurimath::Math.parse(source, type, locale: ...)

Parses a source expression into a Plurimath::Math::Formula. Locale applies to supported text inputs.
