Number formatting support in Plurimath

Suleman UzairRonald Tse

Plurimath now offers precise control over how numbers are presented, enhancing both readability and precision using the number-formatting feature.

Why formatting belongs with the formula

A decimal point, digit grouping delimiter, and scientific notation are not universal presentation choices. A document may require 1,234,567.89, 1.234.567,89, or grouped thin spaces while preserving the same numeric value.

A reusable formatter keeps those decisions together and lets multiple serializers apply them consistently.

1.23456789×108

Create a formatter

Create a Plurimath::NumberFormatter with a locale, then override only the symbols or precision your publication needs.

Ruby
formatter = Plurimath::NumberFormatter.new(
  :fr,
  precision: 2,
  localizer_symbols: {
    decimal: ",",
    group: " ",
    group_digits: 3,
  }
)

formatter.localized_number("1234.56789")

Apply it to a formula

The same formatter object can be passed to formula serializers. This keeps number presentation aligned across AsciiMath, LaTeX, MathML, OMML, and UnicodeMath.

Ruby
formula = Plurimath::Math.parse(
  "sum_(i=1)^10000 i^2121221",
  :asciimath
)

formula.to_latex(formatter: formatter)
